## 1. 背景与目标

Nexus Shared 是 Rust/Axum/SQLite 的跨产品共享能力层，提供 8 个模块：settings、messages、files、
interactions、roles、subject-roles（含 subject-permissions）、departments、subject-departments，
并以 HTTP 转发浏览器 Cookie 到 platformd 的 `GET /crate-api/identity/v1/session` 做认证。

目标：把这套能力**原样迁入 platform（Go）**，由 platformd 单进程单端口（8420）同时提供身份与共享能力：

1. HTTP 契约与 Nexus 保持一致（路由、方法、状态码、JSON 形状、分页、RFC 9457 Problem Details、
   403 的 `required_permission`）；
2. 认证由「转发到 platformd」改为**进程内会话校验**（完整会话），不再需要跨服务调用；
3. 授权门禁保持 043 口径：写路由要求 `access:manage` / `base_data:manage`，管理员（platform_admin）放行；
4. 数据表并入 platformd SQLite，提供一次性数据迁入脚本（Nexus 库与文件目录 → platformd）；
5. Aceso 只改配置指向（`nexus.base-url` → platformd），不改调用代码；
6. `service-nexus-shared/` 在迁移完成后删除（用户 2026-11-13 确认）；删除前归档 `.data`/`logs`。

## 2. 契约映射

| 模块 | 路由（前缀 `/crate-api/v1`） | 读/写门禁 | Go 归属 |
| --- | --- | --- | --- |
| settings | GET/POST `/`，GET/PUT/DELETE `/{id}` | 仅会话 | `internal/shared/settings.go` |
| messages | GET/POST `/`，GET/PUT/DELETE `/{id}`，PATCH `/{id}/status` | 仅会话 | `internal/shared/messages.go` |
| interactions | GET/POST `/`，GET/PUT/DELETE `/{id}` | 仅会话 | `internal/shared/interactions.go` |
| files | GET `/`，POST `/upload`，GET `/{id}`，GET `/{id}/content`，DELETE `/{id}` | 仅会话 | `internal/shared/files.go` |
| roles | GET `/`，GET `/{id}`；写：POST `/`，PUT/DELETE `/{id}` | 写 `access:manage` | `internal/shared/roles.go` |
| subject-roles | GET `/`；写：PUT `/subjects/{subjectID}`；GET `/../subject-permissions` | 写 `access:manage`；`subject-permissions` 查自己仅会话、查他人需 `access:manage` 或平台管理员（043 D5） | `internal/shared/subject_roles.go` |
| departments | GET `/`，GET `/{id}`；写：POST `/`，PUT/DELETE `/{id}` | 写 `base_data:manage` | `internal/shared/departments.go` |
| subject-departments | GET `/`；写：PUT `/subjects/{subjectID}` | 写 `access:manage` | `internal/shared/subject_departments.go` |

共享模块使用 `/crate-api/v1/*`（2026-11-13 用户决定删掉 `/shared` 段；不再是 `/crate-api/shared/v1/*`）。
Aceso 代理改为挂载 `/crate-api/v1/*`，其门禁声明路径同步为 `/v1/*`；前端 `aceso-service-config` 的 nexus `basePath` 同步为 `/crate-api/v1`。

## 3. 关键决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 进程与端口 | 复用 platformd 8420 | 单服务单库，去掉 IDP 转发链路 |
| 数据库 | 并入 `platformd.sqlite`（迁移 000013–000020） | 与 identity 同库，事务与备份简单；Nexus 旧库保留只读 |
| 认证 | 进程内 `identity.CurrentSession`（完整会话） | 契约不变，少一次 HTTP 往返与故障面 |
| CSRF | 共享写路由**不校验** CSRF token | 与 Nexus 一致；调用方是服务端代理，且浏览器直连场景沿用原语义（后续如收紧需跨产品计划） |
| 错误体 | 与 Nexus 完全同形（type=前缀/problems/slug、title、status、detail、403 附 required_permission） | 前端 `problem-message.ts` 已按该形状消费 |
| 分页 | `page` 默认 1、`page_size` 默认 20、上限 100 | 与 Nexus `PageQuery` 一致 |
| 数据迁入 | 一次性脚本（ATTACH 方式由 Go 工具实现） | 无 sqlite3 CLI；脚本幂等、先备份 |
| 旧服务 | 迁移完成后删除代码，数据归档 | 用户 2026-11-13 确认删除；git 历史可回溯 |

### 与 Rust 实现的已知等价性差异（不影响主契约）

| 差异 | Go | Rust | 处置 |
| --- | --- | --- | --- |
| 请求体非法/超限错误的 body | Problem Details | axum 纯文本（400/413） | 更一致，保留 |
| 上传文件名含路径分隔符 | `filepath.Base` 归一化 | 保留原 filename | 更安全，保留（落盘名始终 ULID） |
| 未注册方法/异常路径 | Go mux 的 405/路径清洗 | axum 空体 404/405 | 无消费方依赖，保留 |
| Content-Type 非 JSON | 不校验 | 415 | 无消费方依赖，保留 |
| payload 回显 | 原样字节 | serde 重排 | JSON 语义等价 |
| `role_code` 格式 | 非空、≤64、`[a-z0-9.]` | 同左（不强制首字母小写） | 以 Rust 为准；如需收紧另立计划 |
| `subject-permissions.source` | `"nexus"` | `"nexus"` | 保持兼容字符串 |

## 7. 风险与边界

| 风险 | 处置 |
| --- | --- |
| 契约细节偏差（信封形状不同：settings/messages/interactions/roles/subject-roles 直接返回数组；departments/subject-departments 用 records+meta） | 逐模块以 Rust 测试断言为准，测试方独立复核（已验证） |
| SQLite 写入并发（platformd 单连接池） | 与 identity 一致，`maxconns=1` + WAL；共享模块不做长事务 |
| 文件路径穿越 | 存储名一律服务端 ULID；下载前校验库中路径 |
| 旧 Nexus 仍被 Aceso 直连 | 切换前 Nexus 继续可用；切换后 Aceso 配置指向 8420，旧进程由用户停 |
| 权限码来源 | 同库 `roles.permission_codes`，与 Nexus 一致，不做缓存 |
