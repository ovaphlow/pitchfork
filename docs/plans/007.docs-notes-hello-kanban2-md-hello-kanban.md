## 1. 目标与范围

仅新建 `docs/notes/hello-kanban2.md`，文件内容为单独一行 `hello-kanban2`（末尾可有换行）。如 `docs/notes/` 不存在，由开发在创建该文件时一并创建。

本期不涉及数据库、服务、UI、生产代码、依赖、配置、迁移或其他文档改动。

## 2. 可验证的验收口径

验收时必须在仓库根目录字面执行以下命令并得到退出状态 `0`：

```bash
test -f docs/notes/hello-kanban2.md && grep -q "hello-kanban2" docs/notes/hello-kanban2.md
```

同时人工确认该文件只包含目标文本及可选的末尾换行，且本任务实现未修改其他文件。

## 3. 小步实施步骤

1. 开发：确认 `docs/notes/` 是否存在；不存在时创建该目录。
2. 开发：新建 `docs/notes/hello-kanban2.md`，写入唯一内容 `hello-kanban2`，可保留末尾换行。
3. 开发：在仓库根目录执行本计划第 2 节的硬性验证命令，记录命令和退出状态。
4. 测试：独立检查候选交付中的修改文件范围，并在仓库根目录原样执行硬性验证命令。
5. 评审：核对范围、测试证据和缺陷闭环后，更新本计划的最终状态。
